# Blinkit Power Bi Dashboard
## Project overview
<p> Build a interactive and dynamic power bi Dashboard to analyse blinkit's sales performance and provide a useful and actionable business insights. </p>

## Dataset columns and visuals
<b> A typical Blinkit dataset includes: </b>
<p>
<ul>
<li>Item Fat Content</li>
<li>Item Identifier</li>
<li>Item Type</li>
<li>Outlet Establishment Year</li>
<li>Outlet Identifier</li>
<li>Outlet Location Type</li>
<li>Outlet Size</li>
<li>Outlet Type</li>
<li>Item Visibility</li>
<li>Item Weight</li>
<li>Sales</li>
<li>Rating</li>
</ul>
</p>
<b> Display these cards at the top of the dashboard: </b>
<p>
<ul>
<li>Total salary</li>
Average sales</li>
<li>Average rating</li>
<li>Total items</li>
</ul>
</p>

## Insights
<p>
<ol>
<li>Tier 3 location contribute the most sales.</li>
<li>Foods, Vegetables and Snacks are top selling category.</li>
<li>Supermarket type 1 contribute the largest share of revenue.</li>
</ol>
